# 审查：给导演看之前，先派子代理查一遍

简单的逻辑错误不能留给导演去发现。导演说过：“这些简单的逻辑错误，你应该在给我看之前就已经自己解决了，可以用子代理啊。”

写的人自己查不出自己的错：脑子里有真相，读到哪都觉得“说得通”。所以要派**没见过真相的**子代理去读。

## 派谁
三个一起派，并行跑：

| 谁 | 给它什么 | 不给它什么 | 模型 |
|---|---|---|---|
| **盲测观众** | 这一集的正文，切成一段一个文件 | 一句话、大纲、图谱、规划图、上一轮的意见 | Sonnet |
| **推理迷** | 从案子开始到揭晓之前的全部正文，切成一段一个文件 | 揭晓那段和之后的内容；大纲、图谱 | Sonnet；难的案子用 Opus |
| **找茬** | 正文、图谱、规划图、大纲、导演定死的事 | 写的人的自我辩护 | Opus（实测能查出真问题，三轮左右收敛） |

- 不是悬疑的集，推理迷可以不派。
- 用 Haiku 当观众会把人物张冠李戴，别用它打分。
- **可选的第二意见**：Codex 的 GPT-6-Astra（medium，难的用 high）。
  - 它读不了桌面上的文件夹，要先把材料复制到临时目录，再用 `-C` 指过去。

切正文用脚本，它会去掉“一句话”这类会泄底的部分：
```bash
uv run ~/.claude/skills/storyloom/scripts/blind_pack.py <剧的文件夹> --from 1 --to 1 --out <临时目录>/盲测
uv run ~/.claude/skills/storyloom/scripts/blind_pack.py <剧的文件夹> --from 1 --to 3:7 --out <临时目录>/推理迷   # 到第 3 集第 7 段之前为止
```

## 提示词
每个提示词都要写全：文件路径、要做什么、**只读，不许改任何文件**、输出格式。子代理不知道我们聊过什么。

### 盲测观众
```
你是第一次刷到这部短剧的观众，没看过任何介绍。
剧本正文在 <目录>，一段一个文件（seg01.md、seg02.md……），每段大约 10 秒。

按顺序一个一个读。每读完一个文件，先写一行反应再读下一个：
  第 N 段：我现在以为发生了什么 ｜ 哪里没看懂（没有就写“无”）
不要往回翻，也不要先看后面的文件。只根据读到的内容，不要猜作者的设定。

全部读完后回答：
1. 用三到五句话复述：发生了什么、为什么、结尾让你最想知道什么。
2. 哪个人物你记不住或分不清？
3. 哪句台词你没听懂？照抄出来。
4. 有没有哪里你觉得前后对不上，或者像在骗你？

只读，不许修改任何文件。
```

### 推理迷
```
你是推理迷，喜欢抢在侦探前面猜出凶手。
下面是一部短剧从案子开始到揭晓之前的全部正文，在 <目录>，一段一个文件，按文件名顺序读。

每读完一个文件写一行：第 X 集第 N 段：我现在怀疑谁、为什么（没头绪就写“还没头绪”）。
不要往回翻，也不要先看后面的文件。

全部读完后回答：
1. 你认为是谁干的、为什么、怎么做到的。每一步都要指出你用到的是第几集第几段的哪个线索。
2. 你第一次怀疑对的人，是在第几段？是什么让你怀疑的？
3. 哪个嫌疑人像凑数的：没动机、没机会，或者一看就不是？
4. 哪条线索太明显，或者像硬塞进来的？
5. 有没有不可能做到的地方：时间不够、路走不通、某人不可能知道某件事？

只读，不许修改任何文件。
```
它答完之后，再把真相告诉它（用 SendMessage 接着问同一个子代理），追问一句：“这个真相公平吗？揭晓用到的线索，你之前都看到过吗？哪条没看到？”

看结果的办法（“猜是谁”的案子）：
- 推理迷在案子前半段就很有把握地猜中了，说明太早暴露；
- 推理迷完全没头绪，知道真相后又说“没看到过这条”，说明不公平；
- 最好的结果是：后半段才开始怀疑对的人，知道真相后说“对，我看到过，没想到”。

“看怎么抓”的案子，不看它猜没猜中，看它觉不觉得抓的过程聪明、好看。

### 找茬
```
你是剧本的找茬编辑。要查的是《<剧名>》第 <N> 集。
材料：
- 剧本正文：<路径>（必要时连带前几集：<路径>）
- 故事图谱：<路径>。里面有案子真相、真实时间线（events）、线索表（clues）、地点和规划图坐标（locations、links）
- 规划图：<路径>（图片）
- 大纲：<路径>
- 导演已经定死、不许动的：<列出>

逐项查，没有问题的项写“无”，不要凑数：
1. 空间：每个人每一刻在哪、从哪来往哪去；规划图里有没有这条路、这扇门、这扇窗；隔着门墙看得见、听得见吗；装鬼的人怎么出现、怎么消失。
2. 时间：先后顺序对不对、走路够不够时间、有没有人同一时刻在两个地方。
3. 动机和知识：每个人做的事有没有理由；他知道的事有没有来源；有没有人对眼前的事视而不见。
4. 线索：揭晓用到的每条线索有没有提前上屏；有没有太早暴露凶手；误导线索有没有被推翻；有没有靠运气、巧合、突然出现的新人。
5. 看得懂：观众看一遍会不懂的台词、画面、专业词。
6. 穿帮和能不能拍：上一段结尾和下一段开头接不接得上；道具、衣服、天色、谁在场；一个镜头是不是塞了太多动作；有没有拍不出来的东西。
7. 改动：和大纲、图谱、上一版对不上的地方，分成“有【改】标记的”和“没标记的”。没标记的一律列出来。

每条问题写五样：
- 位置：第几集第几段第几个镜头
- 原句：照抄
- 为什么是问题：观众会怎么想
- 要改成什么结果：说清楚要达到什么，不用替我写台词
- 严重程度：必改 / 建议 / 可选

最后一行写结论：“可以了”或“还要改”。
只读，不许修改任何文件。
```
复查时只给它改过的地方和这一轮的修改清单，让它查两件事：改对了没有，改动有没有带出新问题。

## 查完怎么办
- **必改**：全部改。
- **建议**和**可选**：逐条回剧本核一遍。是真毛病、改了不会带出新问题（更早泄底、段落太长），就改；不改的，对导演说一句为什么。“可选”只说明影响小，不等于可以不管。导演看过可选那几条，觉得“也挺对的”。
- 改完让找茬复查，直到它说“可以了”。盲测复述错的地方，改完再派一个新的盲测（旧的已经看过答案了）。
- 子代理跑不起来时，自己按同样的清单查一遍，并告诉导演“这一轮是我自己查的”。
- 给导演看时，用一两句话说查出了什么、怎么改的，不贴整份报告。
- 子代理只能代替一部分观众。重要的集，建议导演找一个真人读一遍正文，听他复述。
