# 系列维护：大纲、图谱、一案接一案

## 三份东西各管什么
- **大纲**（比如 `大纲-v2.md`）：管方向。
  - 写一句话梗概、地方和楼的格局、人物（性格、口头禅、秘密的方向）、主线。
  - 每个案子写一段方向，最后附后面的案子表。
  - 写给导演看，大白话。
  - 底线只留几条真正的：比如“观众看一遍就懂”“空间以规划图为准”。导演说过“不要有那么多的规矩，把作品拍好就行”，经验类的东西放在本技能里，不堆进大纲。
- **故事图谱**（`故事图谱.json`）：管事实。
  - 人物、关系、地点、真相、真实时间线、线索、每集节拍。
  - 格式见 `故事图谱.md`。
- **剧本**（`EPxx/剧本.md`）：管观众看到的正文。

一件事只在一个地方写全，其他地方引用。比如案子真相写在图谱里，大纲只写一句方向，剧本里不写。

## 写全集大纲：一个写、一个挑
几十集的长剧，先写全集大纲，再写分集。
1. **写**：交给 Opus。
   - 要求只讲方向和底线：这部剧要说什么、审美、好看的地方在哪、观众看完是什么感受，加上时长、能不能拍、尺度这几条硬底线。
   - 不给每集套固定模板（钩子、几个剧情点、旁白、卡点这类格子）。套了模板，每集会长成一个样子，还会逼它为了填格子凑数。
2. **挑**：派找茬逐集挑逻辑漏洞、规则矛盾、拍不出来的情节。
   - 用 Opus，或者 Codex 的 GPT-6-Astra（high）。
3. **改**：按挑出的问题逐条改，再复查一遍。

想比较不同写手时，用“匿名比稿”：
- 同一份要求交给几个模型各写一版，换成甲乙丙丁的编号。
- 请不同公司的模型当评委（同一家的评委会偏向自家）。每个评委用不同的随机编号，对照表放在评委读不到的地方。
- 按统一的标准打分（留人、秘密设计、人物感情、原创、能不能拍、衔接结局），最后再揭晓。
- 2026-10 在《问灵》上实测：
  - Opus 和 Astra 写得最好，水平接近；Sonnet、Sol 其次。
  - Fable 的规则容易前后矛盾，Haiku 最弱。
  - Haiku 当评委，会把不同稿的内容张冠李戴。

## 怎么改
- **就地改**：在原文件里改，标【新增】【改】【删】，不留副本。
  - 改动大的，先把原文件备份到临时目录，不放在剧的文件夹里。
- **下一轮动手前，先清掉上一轮的标记**，只留这一轮的。这样导演打开就知道这次改了什么。
- **定稿的集不轻易动**：新集和旧集冲突时，优先改新集。
  - 非改旧集不可，先问导演。改了标【改】，告诉 manju 只重拍受影响的段。
- **每一处改动都要有记录**：改了设定、人物、空间，就在大纲或图谱里同步，并标出来。
  - 找茬会把“没标记的改动”全部列出来，没记录的就当是改错了。

## 一案接一案，怎么不重复
- **第一个案子要把套路完整演一遍，宁可慢一点**：出事、调查、抓错人、揭穿、收场。观众看懂了这一套，后面才会自带期待。
- **换手法，不换核心**：
  - 核心可以一直是“装神弄鬼被揭穿”；
  - 每个案子换一种装法、一种动机、一种揭穿的办法。
- **顺序互换检验**：把两个案子的顺序对调，故事有没有损失？
  - 没有损失，说明主线没在推进，案子只是在重复。
  - 每个案子都要给主线留一笔账：一个新秘密、一段关系的变化、一个下个案子要用的东西。
- **人物要变**：每个案子之后，主角至少有一点不一样了：多信一个人、少怕一样东西、多欠一笔账。
- **埋暗雷**：每个主要人物身上埋一个秘密，在图谱里标“哪一集引爆”，到时候兑现。
- **这个套路要有终点**：观众知道它会走向什么。不能靠一个比一个更夸张的鬼来续命。

## 一集和下一集怎么接
- 每集结尾留下的写成**事实**：谁拿着什么、谁知道了什么、什么事做到一半。不写“气氛紧张”这种词。
- 下一集开头从这些事实接上。写新一集之前，先读上一集的结尾和图谱里还没兑现的线索、秘密。

## 换会话、换人接手
- 状态都写进文件，不要只存在对话里。
  - 大纲：已定的事；
  - 图谱：每集的 `status`（草稿 / 待查 / 定稿）、真相、线索；
  - memory：导演的口味和这部剧现在做到哪。
- 新会话开工前，先读这三样，再读最近一集剧本。
- 导演的新偏好、新纠正，记进 memory。纠正背后的道理也一起写上，下次才能用到别的地方。
