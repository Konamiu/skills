# Storyloom · 写剧本

Storyloom 把剧本写对，manju 把剧本拍出来。剧本定稿之前不出图、不开 GPU：剧本里改一句最便宜，拍完再改最贵。

## 底线（只有这几条，其余都是经验，按作品需要用）
1. **逻辑说得通**：
   - 每件事都答得出“谁、为什么、怎么做到、什么时候”。
   - 每个人知道的事都有来源，同一时刻只在一个地方。
   - 人物不能对眼前的线索视而不见。
2. **空间对得上**：
   - 以这部剧的规划图和地点数据为准。
   - 规划图里没有的东西（窗户、楼梯、灯）不凭空加；要加就明说“这是新加的”，并同步规划图。
3. **观众看一遍就懂**：
   - 导演就是观众。导演问“啥意思”，就是剧本的错。
   - 关键的事要么上屏，要么说出口一次。
4. **导演拍过板的不擅自改**：比如剧名、人物长相和声音、楼的格局、招牌台词。
   - 想改先问；导演说了可以推翻的（比如剧情），才放开改。
   - 改文件就在原文件里改，标【新增】【改】【删】，不留副本。
   - 下一轮动手前，先清掉上一轮的标记。
5. **先自己查，再给导演看**：
   - 简单的逻辑错误不能留给导演去发现。
   - 每次给导演看之前，都要过一遍第 6 步的审查。

不要给自己（或子代理）堆规矩、定配额（每集几段、几个镜头、几张字卡）。把作品写好看是目的，规矩只是手段。

## 文件放在哪
一部剧一个文件夹，比如 `~/Desktop/Media/漫剧/民宿有鬼/`：

| 文件 | 放什么 | 谁为准 |
|---|---|---|
| `大纲-v2.md`（或同类） | 一句话、地方和格局、人物、主线、每个案子的方向、后面的案子表 | 方向以它为准 |
| `故事图谱.json` | 人物、关系、地点（含规划图坐标）、案子真相、真实时间线、线索表、每集节拍 | **真相、时间线、线索以它为准** |
| `EPxx/剧本.md` | 只放观众看得到的东西：一句话、本集人物、正文（分段、镜头、台词） | 正文以它为准 |
| `对标学习/` | 样板作品的拆解、调研笔记 | 参考 |

剧本里不写真相。这样两处不会各写各的、对不上；盲测时直接把剧本交出去，也不会泄底。格式和填法见 [references/故事图谱.md](references/故事图谱.md)。

## 流程
0. **对齐**：
   - 先读大纲、故事图谱、规划图、上一集剧本，以及 memory 里导演的偏好。
   - 只问导演真正要他拍板的事，比如要不要推翻、走哪个方向、改不改剧名。其余自己按经验定，并说明为什么。
1. **找样板，照着仿**：
   - 写一个新案子或新一季之前，先找一部口碑好、凶手不好猜、线索公平的同类作品，吃透它为什么好看，再把机制换成我们的人物和场地。
   - 拆解存进 `对标学习/`。做法见 [references/仿写.md](references/仿写.md)。
   - 这一步可以派最强的模型（Opus，导演点过可以开最高强度）去调研。
2. **先写真相**：
   - 在故事图谱里写清：凶手是谁、动机、怎么做到；所有相关的人从案子开始到揭晓的真实时间线（没上屏的标 `spoiler`）；每个人知道什么、从哪知道的；真线索、误导线索；嫌疑人各自的动机，以及被排除的理由。
   - 做法见 [references/悬疑逻辑.md](references/悬疑逻辑.md)。
3. **对着规划图走一遍**：
   - 每个人每一刻站在哪、从哪走到哪、看得见谁、听得见什么，都要说得通。
   - 跑检查脚本：`uv run ~/.claude/skills/storyloom/scripts/check_graph.py <剧的文件夹>`。
4. **写分集和正文**：
   - 写在 `EPxx/剧本.md`，按段写镜头和台词。
   - 写法见 [references/节奏与格式.md](references/节奏与格式.md) 和 [references/看得懂.md](references/看得懂.md)。
5. **同步图谱**：每个节拍、线索、事件都对上剧本的集和段号，再跑一遍检查脚本，把“必改”清零。
6. **审查（并行派子代理，自带全部背景）**：
   - **盲测观众**：只给剧本正文。
   - **推理迷**：只给揭晓之前的正文，看能不能太早猜到凶手。
   - **找茬**：给正文、图谱、规划图，查空间、时间、动机、谁知道什么、穿帮、镜头里的动作是不是太多。
   - 查出的问题全部改掉，改完再让找茬复查改过的地方，直到它说“可以了”。
   - 提示词模板和该用哪个模型，见 [references/审查.md](references/审查.md)。
7. **给导演看**：
   - 用大白话讲这一集讲了什么、这轮改了哪里、还有什么没定。
   - 给剧本和大纲的链接；有 Kapi 剧集画布的，告诉他点“重新读取”就能看。
   - 不贴整份剧本，导演要“大概的样子”就给大概。
8. **定稿，交给 manju**：
   - 导演点头后，这一集的 `status` 改成“定稿”，再交给 manju 写分镜、出图、拍摄。
   - 定稿后要是又改，就标【改】，manju 只重拍受影响的段。

## 子代理怎么分（按 `~/.claude/CLAUDE.md` 的路由）
| 活 | 谁做 |
|---|---|
| 找样板、拆解、设计案子（要判断和创作） | Opus；导演要求时开最高强度 |
| 找茬（逻辑、空间、穿帮） | Opus：实测能查出真问题，三轮就能收敛 |
| 盲测观众、推理迷 | Sonnet |
| 第二意见（可选） | Codex 的 GPT-6-Astra：订阅额度，闲着就用 |
| 写或修检查脚本 | Sonnet |

- 创作类的活只给方向、审美和底线，不给模板和配额。
- 检查类的活要写清：路径、只读不改、输出格式。
- Codex 现在读不了桌面上的文件夹（macOS 权限）。派之前先用一条只读的小命令试一下；不行就把要读的材料复制到临时目录，再用 `-C` 指过去。
