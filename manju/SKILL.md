# AI 漫剧工作流

两种做法，开工前先和用户定：

| | 动态漫（comic，默认） | 真人模式（live） |
|---|---|---|
| 单位 | 镜头：一镜一张首帧 | 场：一场一条 4–15 秒的视频，里面 2–4 个镜头 |
| 画面 | 首帧 + 推拉摇；可选去 AI Studio 出视频 | 远程 5090 上的 MiniMax-H3 一次拍出，人真的在动、在说话 |
| 声音 | edge-tts 配音后期加 | 模型自己念台词、对口型；参考声音锁声线 |
| 适合 | 漫画风、旁白多、预算为零 | 真人短剧、连续剧，要“像拍出来的” |

用户要“真人”“连续的”“不是图片拼的”，就用真人模式：读 `references/真人模式.md`，按那里的流程走（check → sheets → voices → live → assemble → qc）。下面六步是两种模式共用的骨架，真人模式在第 3–5 步换成那份文档里的做法。

一集一个文件夹，`分镜.json` 是唯一依据。六步每一步都能单独重跑：哪一镜不满意，改它的描述，只重跑那一镜。

```
写剧本 → 出分镜 → 文生图 → 图转视频 → 剪辑配音 → 自检发布
剧本.md   分镜.json  sheets/frames  handoff   tts/assemble   qc
```

执行器：`uv run ~/.claude/skills/manju/scripts/mj.py <命令> <集目录>`（下面简写成 `mj`）。第一次运行 uv 会自动装好 Pillow 和 edge-tts。需要本机有 ffmpeg；出图需要已登录的 Codex CLI；自检的台词识别需要 whisper-cli（没有就跳过这一项）。

## 集目录

默认放在 `~/Desktop/Media/漫剧/<剧名>/EP01/`（用户说了别的位置就用别的）：

```
EP01/
├── 剧本.md            第 1 步
├── 分镜.json          第 2 步，之后所有步骤都读它
├── assets/角色/       定妆照 lin.png …（sheets 生成）
├── assets/场景/       场景图（sheets 生成）
├── assets/音效/、bgm  音效和配乐（用户提供或另外生成）
├── frames/            每镜首帧 shot01.png …（frames 生成）
├── videos/            每镜视频 shot01.mp4 …（用户在外面出好放进来，可选）
├── audio/             配音 shot02_1.mp3 …（tts 生成）
├── 图转视频清单.md     handoff 生成
└── out/               成片 .mp4、.srt、缩略图、自检报告
```

## 第 1 步 · 写剧本（交给 storyloom）

剧本、大纲、案子、故事图谱都用 **storyloom 技能**（`~/.claude/skills/storyloom/SKILL.md`）来写：照着成熟作品仿、先写真相、对着规划图查空间、派子代理盲测和找茬，导演定稿后再回到这里。manju 这边只管两件事：
- `mj init <集目录> --title 剧名` 建好集目录（storyloom 会把 `剧本.md` 写进去）；
- 合规和旁白的用法见 `references/剧本.md`，写剧本时一并照顾到。

**剧本没定稿，不往下走。** 剧本是后面所有花时间的步骤的根，这里多改一句，比后面重出十张图便宜。

## 第 2 步 · 出分镜

读 `references/分镜.md`（字段和拆镜规矩）和 `references/提示词.md`（画风预设、首帧和视频怎么写）。

1. 把剧本拆进 `分镜.json`（init 已经放好了模板）：角色（外貌锁定 `lock` + 声线 `voice`）、场景、关键道具（`props`）、每一镜。画面里要出现字（刻字、信、招牌）的镜头写 `text_in_frame`；手部、道具特写没有角色时，用 `refs` 挂上前一镜当参考。
2. `mj check <集目录>` 检查：角色有没有设定、台词放不放得下（每秒约 4 个字）、有没有一镜塞了好几个动作。有 ✗ 就改到没有为止，⚠ 的看情况。
3. 把分镜以表格的形式给用户过一遍（镜号、时长、景别、画面、台词），确认后再出图。

## 第 3 步 · 文生图（Codex，免费）

1. `mj sheets <集目录>`：出角色定妆照、场景图、道具图（横图，三视图放得下）。**给用户看定妆照**，长相不满意就改 `lock` 后 `mj sheets <集目录> --only lin --force`。
2. `mj frames <集目录>`：出每镜首帧，会自动带上该镜角色的定妆照和场景图当参考，人物和场景才保持一致。
3. 把首帧拼成一张预览给用户看（可以用 `ffmpeg ... hstack` 或 `tile`），哪镜不行就改那镜的 `image`，`mj frames <集目录> --shots 3,5 --force`。

每张约 1 分钟，同时出 3 张。被安全审核拒绝（safety）时，把动作词换成静止画面的描述再出；卡住会自动停掉。细节见 `references/提示词.md`。

## 第 4 步 · 图转视频

`mj handoff <集目录>` 生成 `图转视频清单.md`：每镜的首帧路径和写好的视频提示词。用户拿去 Google AI Studio（Veo 3.1 Fast，Pro 会员网页出不花钱）、Flow 或即梦出视频，下载后改名放进 `videos/shot03.mp4`。

这一步可以跳过，也可以只做一部分：没有视频的镜头，合成时用首帧加推拉摇（动态漫）。建议先全用首帧合成一版看节奏，再挑关键几镜去出视频。出视频要花用户的额度或钱，开始前先说清楚要出哪几镜、大概多少条。

## 第 5 步 · 剪辑配音

读 `references/声音.md`。

1. `mj tts <集目录>`：按角色声线、台词情绪配音（edge-tts，免费，自动剪掉首尾静音）。用户有克隆声线的音频，就按 `audio/shot03_1.mp3`（第 3 镜第 1 句）放进去，不会被覆盖。
2. 环境音：`mj ambience <集目录> rain`（雨、风、城市、夜、室内、海浪，本机合成，免费），每集都建议铺一层。
3. 配乐和音效：用户提供文件，或者帮他写配乐提示词去生成；写进 `bgm`、每镜的 `sfx`；关键反转那一镜可以 `music_out` 让配乐骤停。
4. `mj assemble <集目录>`：每镜按台词自动定长，视频或静帧裁成竖屏，字幕按说话时间出现，配乐在台词处自动压低，调色加颗粒，左上角“AI生成”标识，响度统一到 -14 LUFS。出 `out/剧名-EP01.mp4` 和 `.srt`。

## 第 6 步 · 自检发布

`mj qc <集目录>`：查画幅、时长、响度、片中黑场，用 whisper 把成片听一遍、和剧本台词比对，出缩略图和 `out/自检报告.md`。

然后**自己看一遍**：打开缩略图看画面连不连贯、人物有没有变脸，抽几帧看字幕位置。告诉用户成片在哪、哪些项没过、哪些需要他亲自看和听（AI 看不到画面动起来的感觉，也听不到配音好不好）。发布清单在报告最后：标题、封面、话题、勾选 AI 生成、音乐授权、正式上线的备案。

## 做事的原则

- **先便宜后贵**：剧本、分镜、定妆照都确认了，再出首帧；首帧都满意了，再出视频。每往后一步，返工成本翻几倍。
- **花钱前先问**：Codex 出图和 edge-tts 免费；出视频、生成配乐、克隆声线可能花钱或占额度，先告诉用户要做什么、大概多少钱。
- **一改就只重跑那一步**：改了台词就 `tts --force` 再 `assemble`；改了画面就 `frames --shots N --force` 再 `assemble`。不要整集重来。
- **把看到的问题说具体**：“第 7 镜男主的领带从红色变成了蓝色”比“有点不一致”有用。
