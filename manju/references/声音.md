# 配音、配乐、音效

## 配音：edge-tts（免费，国内能用）

每个角色在 `characters` 里指定一个 `voice`，全剧不换，观众才认得出是谁。

| 声线 | 性别 | 适合 |
|---|---|---|
| `zh-CN-XiaoxiaoNeural` | 女 | 温暖、成熟，女主、妈妈、旁白 |
| `zh-CN-XiaoyiNeural` | 女 | 活泼、少女感，甜宠女主、小妹妹 |
| `zh-CN-YunxiNeural` | 男 | 阳光少年，男主、学长 |
| `zh-CN-YunyangNeural` | 男 | 沉稳、专业，霸总、长辈、新闻腔 |
| `zh-CN-YunjianNeural` | 男 | 有激情，反派、热血旁白（`narrator` 默认用它） |
| `zh-CN-YunxiaNeural` | 男 | 可爱，小男孩、萌系配角 |
| `zh-CN-liaoning-XiaobeiNeural` | 女 | 东北话，喜剧角色 |
| `zh-CN-shaanxi-XiaoniNeural` | 女 | 陕西话，喜剧角色 |

同一个声线，靠台词的 `emotion` 调语速和音调：平静、温柔、开心、激动、紧张、愤怒、冷漠、悲伤、低语、命令、嘲讽。

两个角色撞了声线（比如两个女配），可以给其中一个固定加一点音调：在 `characters` 里写 `"voice": "zh-CN-XiaoyiNeural"`，所有台词的情绪都选偏低的（冷漠、低语）。

edge-tts 连不上时，会自动退回 macOS 自带的 `say`（声音一般，能出片），成片做好后网络恢复了用 `tts --force` 重配一遍。

**想要更像真人、能克隆声线**：用 IndexTTS2 这类声线克隆（中文、英文、日文效果好，韩语暂不支持）。把生成好的音频按 `audio/shot03_1.mp3` 命名放进去（第 3 镜第 1 句），再跑 `assemble` 就会用你的音频。

## 环境音（每集都建议铺）

`mj ambience <集目录> rain`：本机合成一条 30 秒的环境音，自动写进分镜.json，循环铺满全片，台词时让开一点。可选：`rain` 雨、`wind` 高处的风、`city` 城市远景、`night` 夜虫鸣、`room` 室内底噪、`sea` 海浪。也可以把自己的录音放进 `assets/`，在 `ambience` 里写路径。

没有配乐的时候，至少要有环境音，否则说话之间是死寂，很假。

## 配乐

- 放进集目录，在分镜.json 写 `"bgm": "assets/bgm.mp3"`。比片子短会自动循环，开头淡入、结尾淡出，台词时自动压低。
- 一定要用有授权的音乐：自己用 AI 生成（Suno、Gemini Music 等），或者用平台的可商用曲库。
- 写配乐提示词时说清楚：情绪、速度（BPM）、乐器、哪一秒起高潮、要不要人声（漫剧一般不要）。

## 音效

放在 `assets/音效/`，挂在镜头上：`"sfx": [{"file": "assets/音效/门铃.mp3", "at": 0.3, "volume": 0.8}]`。

最值钱的几个：开门关门、脚步、巴掌、手机震动、心跳、风声、雨声、转场的"嗖"。免费音效可以从 Pixabay、Freesound（注意授权）下载，也可以让 AI 生成。

**静音是武器**：关键时刻（反转、真相揭晓）让配乐停掉，只留环境声，比加任何音效都有冲击力。做法：在那一镜加 `"music_out": true`，配乐会在这一镜开头 0.06 秒内停掉、之后不再响。
