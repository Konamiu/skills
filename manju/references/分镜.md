# 出分镜：分镜.json

`分镜.json` 是这一集的唯一依据：出图、配音、合成、自检都只读它。改什么就改这个文件，然后重跑对应的那一步。

## 顶层字段

| 字段 | 说明 |
|---|---|
| `title`、`episode` | 剧名、第几集（决定成片文件名） |
| `ratio` | `9:16`（抖音/快手默认）、`16:9`、`1:1`、`3:4` |
| `style` | 全片画风，每张图的提示词都会带上（见 提示词.md 的画风预设） |
| `video_style` | 出视频时用的画风描述，不写就用 `style` |
| `negative` | 全片都不要的东西 |
| `grade` | 调色：`cinema`（默认）、`cool`、`warm`、`anime`、`none` |
| `grain` | 颗粒强度，0 关闭，默认 6 |
| `vignette`、`fade`、`subtitles`、`ai_label` | 暗角、开头结尾淡入淡出、烧字幕、"AI生成"角标，默认都开 |
| `ambience`、`ambience_volume` | 环境音（雨、风、城市…），循环铺满全片，台词时让开一点；`mj ambience <集目录> rain` 会自动生成并填好 |
| `bgm`、`bgm_volume` | 配乐文件（相对集目录）和音量（默认 0.35，台词时自动压到 35%） |
| `characters` | 角色：`name`、`lock`（外貌锁定描述）、`voice`（edge-tts 声线） |
| `scenes` | 场景：`name`、`lock` |
| `props` | 关键道具：`name`、`lock`，要刻字就加 `text`。`sheets` 会出道具图，镜头里列了这个道具就自动当参考 |

## 每一镜（shots）

| 字段 | 说明 |
|---|---|
| `id` | 镜号，从 1 开始，文件名都按它来（frames/shot03.png、videos/shot03.mp4） |
| `duration` | 秒数。台词放不下时合成会自动拉长 |
| `size` | 景别：大远景 / 远景 / 全景 / 中景 / 近景 / 特写 |
| `camera` | 运镜：固定 / 缓推 / 缓拉 / 左摇 / 右摇 / 跟拍 / 仰拍 / 俯拍。没有视频时，静帧也会按这个做推拉摇 |
| `scene` | 场景 key |
| `characters` | 画面里出现的角色 key（会自动带上定妆照和外貌锁定） |
| `props` | 画面里出现的道具 key（会自动带上道具图和外貌锁定） |
| `refs` | 额外参考图：`["shot08"]`（第 8 镜的首帧）或集目录里的图片路径。手部、道具特写没有角色时，用它接住前一镜的样子 |
| `text_in_frame` | 这一镜画面里**要有**的字，比如 `伞柄上刻着“苏晚”两个字`。默认全片不要文字，写了这个就只放行这几个字，视频清单里也会要求保持清楚 |
| `image` | **首帧**：这一镜开始那一瞬间的画面 |
| `video` | **视频**：从首帧开始发生的那一个动作 |
| `lines` | 台词：`[{"who": "gu", "text": "……", "emotion": "冷漠"}]`，`who` 可以是 `narrator` |
| `caption` | 画面字（地点、时间、心声），整镜显示在画面上方，不配音 |
| `sfx` | 音效：`[{"file": "assets/音效/门铃.mp3", "at": 0.5, "volume": 0.8}]`，`at` 是镜头内的秒数 |
| `video_in` | 用视频的第几秒开始（跳过 AI 视频开头的"起步"） |
| `speed` | 视频播放速度，默认 1 |
| `music_out` | true 时配乐在这一镜开头骤停、到片尾不再响（反转、真相揭晓时用） |
| `lip_sync` | true 时清单里会把台词写进视频提示词，让模型对口型；默认不对口型，配音后期加 |

## 拆镜的规矩（每一条都是踩过的坑）

1. **一镜只做一个动作。** 视频模型 5–8 秒只能把一个动作做好。"推人、撞栏杆、翻过去、抓住楼沿"要拆成四镜，靠剪辑接起来。写了两个以上"然后、接着"的，`check` 会提醒。
2. **首帧只画开头那一瞬间。** 动作的过程交给视频，首帧里不要画"正在翻下去"。
3. **复杂物理动作换个好拍的机位。** 人翻栏杆，从侧面拍一定穿模；从楼外仰拍、人朝镜头翻过来就自然。画面里尽量别让人和栏杆、门框交叠。
4. **时长先按台词算。** 每秒约 4 个字，再加 0.3 秒开口前的停顿、0.4 秒说完的余韵。
5. **景别要有变化。** 远—中—近交替，对话用正反打（A 的近景 → B 的近景），情绪最高点给特写。
6. **镜头之间要接得上。** 上一镜结尾观众正看着的东西，下一镜开头接住；机位留在轴线同一侧；新出现的人物要交代从哪来。
7. **镜头数按时长定**：30 秒 8–12 镜；1 分钟 15–20 镜；2 分钟 25–35 镜。 对话镜 2–3 秒，剧情推进 3–5 秒，空镜和转场可以长一点。

## 角色锁定（lock）

把每个角色的外貌写成一段固定的话，每张图原样带上，再配上定妆照，人物就不会走样。写清楚这几样：年龄、脸型和五官特征（一颗痣、单眼皮）、发型发色、服装（颜色和款式）、体型。不要写情绪和动作，那些放在每镜的 `image` 里。

换装就新建一个角色 key（比如 `lin_dress`），定妆照单独出。
